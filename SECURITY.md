# Security policy

Security fixes target the current application release. Upgrade before reporting a problem that has already been fixed.

Please report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/timorpic/Navelix/security/advisories/new). If the private reporting form is unavailable, contact the maintainer through their [GitHub profile](https://github.com/timorpic) to arrange a private channel. Do not publish exploit details or credentials in a public issue.

Include the affected version, deployment/proxy configuration, prerequisites, minimal reproduction, and expected impact. Use synthetic accounts and an isolated `NAVELIX_DATA_DIR`; exclude databases, API tokens, initial passwords, license credentials and private EE artifacts. Please allow the maintainer time to verify and prepare a fix before public disclosure.
