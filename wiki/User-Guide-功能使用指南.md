## 1. 🔖 网址导航与资产库管理

### 1.1 分类与色彩系统
- **无限自定义分类**：支持创建包含专属 Emoji 图标、中文名称与标签缩写的分类；
- **拖拽与快捷访问 (Quick Access)**：
  - 点击卡片上的 ⭐ 星标可将高频网站加入顶部「快捷访问」栏；
  - 侧边栏支持按分类一键过滤与全局模糊搜索（支持按标题、URL、描述即时检索）。

### 1.2 浏览器书签导入与全量导出
- **HTML 书签导入**：支持从 Chrome、Edge、Safari、Firefox 导出的 `bookmarks.html` 文件一键导入，系统自动解析文件夹层级并映射为分类；
- **全量 JSON 备份与迁移**：支持导出当前用户全量书签、项目、日程与设置的结构化 JSON，方便在不同服务器间迁移。

### 1.3 全站链接健康自动巡检
- **自动探活**：后台内置轻量级探活引擎，定时检测链接的 HTTP 状态（200 OK、404 Not Found、500 Error 等）；
- **故障标记**：失效链接在卡片上显示状态警示点，点击即可快速修正或下架。

## 2. 📊 项目管理与 21 天交互式甘特图

### 2.1 四维项目健康度看板
每个项目卡片均提供直观的四维实时指标：
1. **🟢 进度 (Progress %)**：基于已完成动作清单项占比自动计算；
2. **🟢 任务 (Tasks Count)**：实时显示 `已完成 / 总任务数`；
3. **🟡 风险 (Risk Level)**：基于逾期任务数量与工期紧迫度自动评估（`正常` / `注意` / `高风险`）；
4. **⏱️ 最近更新 (Last Activity)**：团队任意成员更新任务或里程碑时毫秒级刷新（支持多用户协同感知）。

### 2.2 21 天交互式甘特图时间轴
- **全局时间跨度**：展示 `过去 7 天 + 今天 + 未来 14 天` 的动态时间轴；
- **里程碑分布**：清晰可视化每个项目在时间轴上的任务节点分布与截止日期；
- **点击交互**：点击甘特图中的任意任务节点即可快速查看详情或标记完成。

### 2.3 已拆解动作清单实时编辑
- 在项目卡片或列表页点击 **「编辑」**：
  - 支持对项目名称、描述、状态色彩进行修改；
  - 支持直接在弹窗中**增删改查已拆解的动作清单与里程碑**，提交后自动完成数据库原子级事务更新。

## 3. 📅 日历日程、多人协同与智能顺延

### 3.1 本地时区精准对齐
- 系统底层全面采用 `toLocalDateStr()` 本地日期处理函数，杜绝因 UTC 时区转换导致的“跳日”或“昨日未完成显示在今天”等时差 Bug。

### 3.2 团队成员分工与指派
- **成员拉取**：创建或编辑待办时，支持从下拉列表中选择团队成员作为责任人；
- **多端呈现**：卡片上直观呈现责任人头像或昵称徽章，便于协同跟进。

### 3.3 逾期任务智能顺延 (Rollover)
- 当由于突发变动导致前几日的待办未完成时：
  - **顺延至今天**：一键将所有过期待办截止日期顺延至今日；
  - **顺延至本周**：系统根据剩余工作日将逾期任务均匀平摊到本周后续日期。

### 3.4 外部日历订阅 (Apple / Google / Outlook)
- 进入日历页面复制您的专属 Webcal 订阅链接：
  ```text
  webcal://your-navelix-domain.com/api/calendar/export?token=nvx_live_YOUR_TOKEN
  ```
- 在 iPhone / Mac 日历中添加订阅，手机日历即可每 15 分钟自动与 Navelix 工作台日程双向同步！

## 4. 🤖 AI 智能工作流与大模型监控

### 4.1 AI 项目智能拆解与分工
- 在创建项目时点击 **「✨ AI 智能拆解」**：
  - 输入项目名称（如“Q3 官网改版”）与目标描述；
  - AI 自动基于系统当前**实时团队成员名单**与启动日期，智能拆解为 4~6 个具体的阶段性里程碑、截止工期与推荐责任人；
  - 支持一键采纳并直接写入项目动作清单。

### 4.2 AI 每日日程规划建议
- 每日清晨登录工作台时，AI 助理根据当天的待办清单、项目工期与紧急程度，自动生成今日核心攻坚建议。

### 4.3 工作空间全量上下文 AI 对话
- 右侧边栏内置 Copilot 智能助手，自动注入当前用户的所有书签、项目与日程实时上下文，支持直接提问：“帮我汇总下本周要截止的项目”或“找一下开发分类下的 GitHub 工具”。

### 4.4 商汤 SenseNova 大模型用量监控
- **实时配额大盘**：直观呈现 DeepSeek-V4、GLM-5.2、SenseNova-6.8 等模型当前 5 小时计费窗口内的剩余调用百分比与健康度条；
- **凭据安全保护**：采用服务端加密存储，跨设备登录时密码保持留空不变逻辑，后台清晰显示 `(✓ 服务端已保存)`；
- **前台显隐控制**：在后台关闭显隐开关时，前台侧边栏对应的卡片容器彻底从 DOM 中隐藏，不占用任何界面空间。

## 5. 🎨 个性化外观与系统设置

- **主题模式**：支持 `浅色 (Light)`、`深色 (Dark)` 与 `跟随系统 (System)`；
- **壁纸模式**：支持 `无壁纸 (极简)`、`必英每日壁纸 (Bing Daily)`、`自定义壁纸 URL` 与 `毛玻璃特效 (Glassmorphism)`；
- **布局宽度**：支持 `1000px`、`1200px` (标准)、`1400px` (宽屏) 与 `Full 全屏`；
- **搜索引擎**：支持 Google、百度、Bing、Perplexity 以及自定义搜索 URL 模板（如 `https://search.example.com?q=%s`）；
- **品牌定制**：自定义网站标题、自定义 Logo 图标、自定义页脚文案与社交联系方式。

---

## 6. 💾 数据备份与跨端同步

- **跨设备毫秒级云同步**：在 iPad / 手机上修改的任意偏好设置与数据，通过服务端 SQLite 数据库中心化存储，打开电脑即刻无缝漫游呈现；
- **数据库物理快照一键热备**：管理员可在后台一键生成并下载当前 SQLite 的 `.db` 二进制物理备份文件，支持上传文件在线一键还原。
