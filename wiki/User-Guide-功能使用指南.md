## 1. 🔖 网址导航与资产库管理

### 1.1 分类与色彩系统
- **无限自定义分类**：支持创建包含专属 Emoji 图标、中文名称与标签缩写的分类；
- **快捷访问 (Quick Access)**：
  - 「快捷访问」栏的置顶项在 **后台 → 链接管理** 中切换（前台书签卡片上**没有**星标按钮）；
  - 侧边栏支持按分类一键过滤；顶部搜索框为**系统内全类型搜索**（书签 / 项目 / 待办 / 分类等），输入即实时展示结果，提交不做外部跳转。

### 1.2 浏览器书签导入与全量导出
- **HTML 书签导入**：支持从 Chrome、Edge、Safari、Firefox 导出的 `bookmarks.html` 文件一键导入，系统自动解析文件夹层级并映射为分类；
- **全量 JSON 备份与迁移**：支持导出当前用户全量书签、项目、日程与设置的结构化 JSON，方便在不同服务器间迁移。

### 1.3 链接存活与延迟探针（Pro）

> ⚠️ 本节能力为 **Pro 专享**，且需要官方 EE 驱动。未激活 / 未安装驱动时接口返回 `EE_DRIVER_MISSING` 或 `PRO_REQUIRED`，链接会恒定显示为离线。

- **实时延迟探针**：书签卡片右上角显示网络响应速度分级（🟢 <350ms / 🟡 350~1500ms / 🔴 离线）；
- **服务端代理探测**：由服务端发起请求，规避浏览器跨域与混合内容限制，单个请求最多探测 25 个 URL。

### 1.4 书签笔记与 AI 摘要
- **Markdown 笔记**：新增 / 编辑书签时可填写 Markdown 笔记，随书签一同保存；
- **AI 网页摘要**：点击「✨ AI 抓取并生成 Markdown 摘要」可让服务端抓取该网页并由 AI 生成结构化摘要（未配置 AI Key 时返回内置兜底摘要）。

## 2. 📊 项目管理与多尺度甘特图

### 2.1 四维项目健康度看板
四维指标位于**首页「工作空间概览」**中当前选中的那个项目（项目卡片本身只显示「里程碑达成度 `已完成 / 总数`」与关联日程待办）：
1. **🟢 进度 (Progress %)**：基于已完成动作清单项占比自动计算；
2. **🟢 任务 (Tasks Count)**：实时显示 `已完成 / 总任务数`；
3. **🟡 风险 (Risk Level)**：基于逾期任务数量与工期紧迫度自动评估，取值形如 `N项逾期` / `近期攻坚` / `风险可控`；
4. **⏱️ 最近更新 (Last Activity)**：记录项目最近一次被更新的时间，跨设备刷新后即时呈现最新进度。

### 2.2 多尺度交互式甘特图时间轴
甘特图支持三档时间尺度缩放，从微观排期到跨年战略规划均可覆盖：
- **🌞 日视图（21 天敏捷视窗）**：展示 `过去 3 天 + 今天 + 未来 17 天` 的动态时间轴，聚焦近三周微观排期；
- **📅 月视图（12 个月年度推进）**：以月为刻度查看全年任务分布，适合中期项目；
- **🪐 年视图（3 年路线图 = 12 个季度）**：跨年战略路线图，适合长期规划。
- **里程碑分布**：清晰可视化每个项目在时间轴上的任务节点分布与截止日期；
- **点击交互**：点击甘特图中的任意任务节点即可快速查看详情或标记完成。

### 2.3 已拆解动作清单实时编辑
- 在项目卡片或列表页点击 **「编辑」**：
  - 支持对项目名称、描述、状态色彩进行修改；
  - 支持直接在弹窗中**增删改查已拆解的动作清单与里程碑**，提交后自动完成数据库原子级事务更新。

## 3. 📅 日历日程、成员分工与智能顺延

### 3.1 本地时区精准对齐
- 系统底层全面采用 `toLocalDateStr()` 本地日期处理函数，杜绝因 UTC 时区转换导致的“跳日”或“昨日未完成显示在今天”等时差 Bug。

### 3.2 成员分工与指派
- **成员拉取**：创建或编辑待办时，支持从下拉列表中选择成员账号作为责任人；
- **多端呈现**：卡片上直观呈现责任人头像或昵称徽章，便于多端跟进。

### 3.3 逾期任务智能顺延 (Rollover)
- 当由于突发变动导致前几日的待办未完成时：
  - **顺延至今天**：一键将所有过期待办截止日期顺延至今日；
  - **顺延至本周**：将逾期任务按「今天 → 周日」的**自然天数**轮转平摊（`序号 % 剩余天数`），**不排除周六周日**。

### 3.4 日历导出与外部订阅 (Apple / Google / Outlook)
- **界面内导出**：日历页面的 iCal 弹窗提供一键**下载** `.ics` 文件（`GET /api/calendar/export`），可手动导入手机 / 电脑日历；
- **订阅式同步**：如需让外部日历定期自动拉取，可自行在日历应用中「新建日历订阅」并手工填入以下地址（**界面暂不提供复制按钮**）：
  ```text
  webcal://your-navelix-domain.com/api/calendar/export?token=nvx_live_YOUR_TOKEN
  ```
- ⚠️ 注意这是**单向导出**（Navelix → 外部日历）：系统没有日历导入接口，在外部日历上的改动不会回写 Navelix。

## 4. 🤖 AI 智能工作流与大模型监控

### 4.1 AI 项目智能拆解与分工
- 在创建项目时点击 **「✨ AI 智能拆解」**：
  - 输入项目名称（如“Q3 官网改版”）与目标描述；
  - AI 自动基于系统当前**成员名单**与启动日期，智能拆解为 4~6 个具体的阶段性里程碑、截止工期与推荐责任人；
  - 支持一键采纳并直接写入项目动作清单。

### 4.2 AI 每日日程规划建议
- 在**日历页面点击「✨ AI 智能排程」按钮手动触发**（不会在登录时自动生成）；AI 助理根据当天的待办清单、项目工期与紧急程度，生成今日核心攻坚建议与建议任务列表。

### 4.3 工作空间全量上下文 AI 对话
- 右侧边栏内置 Copilot 智能助手，自动注入当前用户的所有书签、项目与日程实时上下文，支持直接提问：“帮我汇总下本周要截止的项目”或“找一下开发分类下的 GitHub 工具”；
- **可代你执行写操作**：Copilot 具备工具调用能力，能直接创建 / 修改 / 删除待办与项目（删除类操作会二次确认），例如「帮我把明天的评审加进待办」。

### 4.4 反重力 / Codex 账号额度监控
- **实时额度大盘**：右侧边栏「模型监控」卡片直观呈现反重力（Claude / Gemini 的 5 小时、7 天窗口）与 Codex（30 天窗口）的剩余调用百分比与健康度进度条；
- **OAuth 一键授权**：反重力账号通过 Google OAuth 授权连接，Codex 通过 OpenAI 授权连接，令牌由服务端 AES-256-GCM 加密落库，不保存明文密码；
- **密钥配置**：反重力 Google OAuth 客户端密钥**已内置官方配套默认值，开箱即用免配置**；如需换成自己的 OAuth 应用，可在「后台 → **系统设置** → 系统与数据管理 → 🔐 反重力 OAuth 配置」中覆盖，覆盖值会安全存储于数据库。

## 5. 🎨 个性化外观与系统设置

- **主题模式**：支持 `浅色 (Light)`、`深色 (Dark)` 与 `跟随系统 (System)`；
- **壁纸模式**：支持 `无壁纸 (极简)`、`必英每日壁纸 (Bing Daily)`、`自定义壁纸 URL` 与 `毛玻璃特效 (Glassmorphism)`；
- **布局宽度**：支持 `1000px`、`1200px` (标准)、`1400px` (宽屏) 与 `Full 全屏`；
- **搜索**：内置**系统内全类型搜索**（书签 / 项目 / 待办 / 分类等），输入即出结果；**不再支持也无需配置外部搜索引擎**（旧版的自定义搜索引擎配置列已在数据库迁移 v10 中移除）；
- **品牌定制（Pro）**：自定义网站标题、自定义 Logo 图标、自定义页脚文案与社交联系方式。
  ⚠️ 未激活许可证时，这些字段会被服务端**强制重置为默认值**，前台改动不会保存；
- **自定义代码与统计探针注入（Pro）**：注入自定义 CSS 与 `<head>` 脚本；同样受许可证门禁保护，未激活时会被清空。

## 6. 💾 数据备份与跨端同步

- **跨设备无缝漫游**：在 iPad / 手机上修改的任意偏好设置与数据，通过服务端 SQLite 数据库中心化存储，打开电脑即刻呈现最新状态；
- **数据库物理快照一键热备**：管理员可在后台一键生成并下载当前 SQLite 的 `.db` 二进制物理备份文件，支持上传文件在线一键还原；
- **云端异地容灾（Pro）**：可在后台配置 S3 / WebDAV 云端存储（AWS S3、Cloudflare R2、阿里云 OSS、腾讯云 COS、MinIO、坚果云/群晖 WebDAV），支持每日自动快照同步、云端快照列表与一键还原；未激活许可证时该模块接口返回 403。

## 7. 🔔 消息通知与专注统计

### 7.1 消息通知中心
- 侧边栏一级入口 **「消息通知」**，按来源分类筛选：API 调用、日历、项目、系统、链接等；
- 支持单条标记已读（`PATCH /api/notifications/{id}`）与一键全部已读（`POST /api/notifications/read`）；
- 后台顶栏有通知铃铛与未读计数。

### 7.2 Telegram Bot 推送
- 可在后台配置 Telegram Bot，将**备份结果、服务重启、磁盘占用告警、登录异常**等事件推送到你的 Telegram；
- 登录连续失败时也会触发安全告警。

### 7.3 专注时长统计
- 首页顶栏显示 **「今日专注」** 指标，右侧栏「专注统计」小组件展示周趋势；
- 统计方式是**被动累积**：页面保持打开即自动累加停留时长（**不是番茄钟**，没有计时/开始/暂停/倒计时功能）。
