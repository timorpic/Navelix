# 项目规格

## 定位与目标用户

Navelix（Personal Digital Hub）是面向开发者、极客和独立创作者的自托管个人数字工作空间。将网址入口、项目任务、日程与 AI 辅助集中到同一应用，支持浏览器、扩展及 API 采集。

核心目标是降低常用信息和行动清单的切换成本，通过本地 SQLite 简化部署，并支持个人数据归属与权限隔离。多用户能力不等同于完整企业项目协作平台。

## 访问与商业边界

默认私有访问；管理员显式启用公开访问后，访客可浏览指定主用户的公开工作空间。个人管理后台要求登录，系统级操作仍需管理员权限；分享页使用独立分享令牌校验。

仓库包含 CE 基础实现与 EE 桥接接口。云存储、链接探针和部分品牌/脚本定制等能力受驱动可用性与许可门禁约束；源码运行不保证具有官方 Pro 镜像的全部能力。具体以 `src/lib/ee-gate.ts`、`ee-bridge/` 和 [LICENSE](../LICENSE) 为准。

## 非功能要求

- 本地优先：核心业务持久化无需外部数据库；迁移保留已有用户数据。
- 数据隔离：每次读写验证身份、角色与对象归属；访客读取不泄露敏感配置。
- 隐私透明：AI、天气、云存储、账号监控和匿名遥测可能访问外部服务，应准确说明配置与关闭方式，不承诺所有网络数据都留在本机。
- 可用性：深浅主题、窄屏与键盘可操作，提供加载、空态和失败反馈。
- 可维护性：复用业务与安全入口，保留测试与构建门禁，版本与更新日志可追溯。
